Clew 0.1 使用说明（第一个试用版）
====================================

【打开】
1. 把整个压缩包解压到一个文件夹（比如 D:\Clew）。不要直接在压缩包里双击运行。
2. 双击文件夹里的 Clew.exe。
3. 这个软件没有做数字签名，Windows 第一次可能弹出“Windows 已保护你的电脑”。
   点“更多信息”→“仍要运行”即可。以后不会再问。
4. 想放到桌面：右键 Clew.exe →“发送到”→“桌面快捷方式”。

【第一次设置（必须）】
1. 点右上角齿轮进入 Settings。
2. 在 MiMo / Kimi / DeepSeek 任意一个（或全部）里粘贴 API key，点“Save & test”。
   显示 CONNECTED 就是通了；失败会在下面显示原因。
3. “Brain”选一个已连通的模型：它负责写标题、摘要、归主题、连链条。
4. “Eyes”选一个能看图的模型，用来读截图里的文字。不是每个模型都支持看图；
   如果失败，软件会退回只用你的配文，不会卡住。
5. Kimi：在 platform.moonshot.cn 申请的 key，用默认地址 https://api.moonshot.cn/v1；
   在 platform.kimi.ai / moonshot.ai 申请的 key，把 Base URL 改成 https://api.moonshot.ai/v1。
6. 模型名可以改。默认值是 2026 年 11 月查到的：mimo-v2.5-pro、kimi-k2.6、deepseek-v4-flash。
   如果服务商改名了，在 Model 一栏换成新名字即可。

【日常用法】
- 底部输入框：贴链接、打字、或者 Ctrl+V 粘贴截图，按回车或点 Log。
- 链接后面空一格再写字，那段字会作为你的附言一起存。
- 截图粘贴后，可以在输入框写一句出处再点 Log。
- 地球按钮是内置浏览器。在里面登录一次微信、X、小红书、付费网站，
  以后在这些网站上点“Log this page”就能收录；直接贴这些网站的链接也会用到你的登录状态。
- 每张卡片底部“See the chain / More”可以展开链条、加批注、设回看日期、重新处理、删除。

【数据在哪】
- 所有内容存在你自己电脑上：%APPDATA%\Clew\data（Settings 最下面有“Open the folder”按钮）。
- clew-data.json 是全部数据，images 文件夹是截图。复制这个文件夹就是备份。
- API key 用 Windows 自带的加密存储，不是明文。

【这一版还没做 / 已知限制】
- 主题需要凑够 3 条相关内容才会成形（可在 Settings 改数字），之前都在 Unsorted 里。
- 一条内容只挂一条事件链；同时属于两个主题时，链条跟第一个主题走。
- 主题页的“变化”只列出新增条目标题，还没有 AI 写的摘要。
- 主题不能合并，只能改名、加别名。
- PDF 链接读不出正文。
- 没有自动更新：有新版本时，用新文件夹替换旧的 Clew 程序即可，数据不受影响（数据在 %APPDATA% 里，不在程序文件夹里）。
- 图标还是 Electron 的默认图标。
